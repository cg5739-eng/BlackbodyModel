# BlackbodyModel 
Contained with this directory are simplified versions of the high-fidelity blackbody model. Below are a few examples of what an output of this model looks like. <br><br>
Context: both of these models are set to heat to a temperature of 500 K. Time scales and physical constants have been modified to unrealistic values.
![simple model](https://github.com/user-attachments/assets/2bc2ff55-b074-4347-8e3b-1fe1d4780439)
*You can run this code with the bb2D.m file*
This illustrates a primitive blackbody model, which accounts for only heat diffusion, radiation, and proportional controllers for regulation of temperature. 

![full model](https://github.com/user-attachments/assets/b6984766-0120-458d-b11e-cbf03f8b7d61)
The full model accounts for square heater geometries and, as seen above, helps visualize uniformity on the surface of the blackbody.
